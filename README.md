# MEMORIA — сайт фотостудии

Статический одностраничный сайт фотостудии с формой заявки на фотосессию. Оформлен в стилистике интерфейса Animus. Сборка не нужна: чистые HTML, CSS и JS, поэтому сайт сразу публикуется на GitHub Pages.

## Структура

```
index.html               — вся разметка страницы
css/style.css            — стили
js/config.js             — настройки (куда отправлять заявки)
js/main.js               — анимации, галерея, форма
assets/favicon.svg       — иконка вкладки
.github/workflows/       — автодеплой на GitHub Pages
```

## Публикация на GitHub Pages

1. Создайте на GitHub пустой репозиторий, например `memoria-studio`.
2. Загрузите в него файлы:
   ```bash
   git init
   git add .
   git commit -m "Сайт фотостудии"
   git branch -M main
   git remote add origin https://github.com/<ваш-логин>/memoria-studio.git
   git push -u origin main
   ```
3. В репозитории откройте **Settings → Pages** и в поле **Source** выберите **GitHub Actions**.
4. Через минуту сайт будет доступен по адресу `https://<ваш-логин>.github.io/memoria-studio/`.
   Каждый следующий `git push` в `main` обновляет сайт автоматически.

## Как принимать заявки

GitHub Pages только раздаёт файлы и не умеет обрабатывать формы, поэтому заявки принимает бесплатный внешний сервис. Его адрес указывается в `js/config.js` в поле `formEndpoint`.

**Formspree** (рекомендуется)
1. Зарегистрируйтесь на <https://formspree.io> и создайте форму (New Form).
2. Скопируйте адрес формы вида `https://formspree.io/f/abcdwxyz`.
3. Вставьте его в `js/config.js`:
   ```js
   formEndpoint: 'https://formspree.io/f/abcdwxyz',
   ```
Заявки будут приходить на почту и храниться в кабинете Formspree. На бесплатном тарифе — 50 заявок в месяц.

**FormSubmit** (без регистрации)
```js
formEndpoint: 'https://formsubmit.co/ajax/ваша@почта.ru',
```
После первой заявки FormSubmit пришлёт письмо, в котором нужно подтвердить адрес.

Пока `formEndpoint` пустой, форма работает в демо-режиме: заявка не отправляется, а выводится в консоль браузера, и пользователь видит об этом предупреждение.

## Что заменить на своё

- **Фотографии.** В галерее сейчас стоят случайные фото-заглушки с picsum.photos. Положите свои снимки в `assets/gallery/` и поменяйте `src` у тегов `<img>` в блоке `#gallery` в `index.html`. Категория фото задаётся атрибутом `data-cat`: `portrait`, `love`, `family` или `fashion`.
- **Контакты.** Адрес, телефон, почта и соцсети находятся в блоке `#contacts`.
- **Цены и услуги.** Меняются в блоках `#services` и `#pricing`. Если меняете название услуги, поменяйте его и в кнопке `data-service`, и в соответствующем варианте формы, чтобы кнопка «Выбрать» продолжала работать.
- **Часы записи.** `openHour` и `closeHour` в `js/config.js`.

## Локальный просмотр

Достаточно открыть `index.html` в браузере. Можно также запустить локальный сервер:
```bash
python -m http.server 8000
```
и открыть <http://localhost:8000>.
