# MEMORIA: портфолио с галереями

Сайт на GitHub Pages + локальная админка, куда фото просто перетаскиваются.

## Админка (на твоём ПК)
1. Один раз поставь Python (python.org, галочка **Add to PATH**).
2. Запусти `admin/start.bat`. Откроется http://localhost:8765.
3. «+ Новая галерея» → перетащи фото в папку → при желании добавь папки («Для соцсетей», «Полный размер» и т.д.).
   - ☆ на фото делает его обложкой, ✕ удаляет.
   - Галочка «скрытая»: галерея не видна на главной, открывается только по ссылке («Копировать ссылку» и отправляешь модели).
4. «Опубликовать на сайт» откроет GitHub Desktop: там нажми **Commit to main**, затем **Push origin**. Через минуту сайт обновится.

Превью делаются автоматически, оригиналы сохраняются как есть и скачиваются с сайта.

## Сайт
Адрес: https://garethdemon.github.io/Plenka-studio/ (репозиторий GarethDemon/Plenka-studio, деплой через GitHub Actions).

## Что где
- `index.html`, `css/`, `js/`: главная (услуги, тарифы, контакты, карточки галерей)
- `gallery.html`: страница галереи (вкладки, просмотр, скачивание)
- `data/galleries.json`, `photos/`: данные и фото, правит админка
- `js/config.js`: имя фотографа на обложке галереи

Важно: скрытая галерея доступна всем, у кого есть ссылка, это не пароль.
